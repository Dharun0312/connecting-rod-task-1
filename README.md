# Connecting Rod Assembly — CATIA V5

**Task 1 · CAD assembly**

This repository contains the native CATIA V5 assembly file and its component parts.

## Files

- `CONNECTING ROD.CATPart.CATProduct` — main CATIA product assembly
- `CONNECTING ROD.CATPart` — connecting rod component
- `BIG END CAP.CATPart` — big-end cap component
- `BOLT8.CATPart` — bolt component
- `NUT.CATPart` — nut component

## Open the assembly

1. Download all repository files together, or use **Code → Download ZIP**.
2. Extract the files into one folder.
3. Open `CONNECTING ROD.CATPart.CATProduct` in CATIA V5.
4. Keep the component `.CATPart` files beside the product file so the assembly links can resolve.

## Preview

GitHub stores the native CATIA files but does not render them as an interactive 3D preview. Download the files and open them in CATIA V5 to inspect the model.
